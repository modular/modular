# Mojo compiler contributor guide

## Contribution Areas

For the latest status on what areas of the Mojo compiler are open to
contributions, please visit our
[Contribution Areas](https://mojolang.org/community/contributing/contribution-areas/#compiler)
page.

## Style Guide

C++ code in the compiler follows the
[C++ coding standard](./CPPCodingStandard.md). Run `./bazelw run //:format`
before you open a PR. Otherwise, follow the rest of the
[Mojo contributor guide](../README.md).

## Onboarding

To learn about the Mojo compiler codebase, see the compiler documentation in
GitHub at
[`Mojo/docs/compiler`](https://github.com/modular/modular/tree/main/Mojo/docs/compiler).
