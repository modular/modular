Model code reads and writes tensor values using four operations, and which one
to use depends on what's known at write time. A fixed position or range, like
the last token in a sequence or a window of attention heads, uses Python slice
syntax directly. Positions computed at runtime, like token IDs from a sampler or
expert assignments from a router, require
[`F.gather`](/api/python/experimental.functional/#max.experimental.functional.gather),
which takes a tensor of indices and returns the selected values. When a boolean
condition determines which values to keep,
[`F.where`](/api/python/experimental.functional/#max.experimental.functional.where)
selects element-wise from two tensors based on a mask. To write values to
specific positions, use
[`F.scatter`](/api/python/experimental.functional/#max.experimental.functional.scatter).

:::note Coming from PyTorch or NumPy?
Integer, range, and `...` indexing follow PyTorch and NumPy conventions. For
index lists or boolean masks, use `F.gather` or `F.where`.
`F.where(cond, x, y)` takes its arguments in the same positional order as
`torch.where`.

`F.gather` differs from `torch.gather`. PyTorch's `torch.gather` requires
`index` to have the same rank as `input` and returns a tensor with the shape of
`index`. MAX's `F.gather` replaces the `axis` dimension of `input` with the
full shape of `indices`, producing shape
`[*shape[:axis], *indices.shape, *shape[axis+1:]]`. This matches `np.take` and
`torch.index_select`.
:::

## Extract values by position

Slice syntax works the same way it does in Python, NumPy, and PyTorch: `x[i]`
selects by index, `x[a:b]` selects a range, and negative indices count from the
end.

```python
from max.experimental.tensor import Tensor

hidden = Tensor.ones((2, 4, 8))  # (batch=2, seq_len=4, features=8)

print(hidden[0].shape)  # drop batch dim
print(hidden[:, 1:3].shape)  # window along seq_len
print(hidden[:, -1].shape)  # last token
print(hidden[..., -1].shape)  # last feature, any rank
```

The expected output is:

```text
[Dim(4), Dim(8)]
[Dim(2), Dim(2), Dim(8)]
[Dim(2), Dim(8)]
[Dim(2), Dim(4)]
```

When the position is computed at runtime, like token IDs from a sampler or
expert assignments from a router, use `F.gather`.

## Select elements by index

When positions are data rather than literals,
[`F.gather(input, indices, axis)`](/api/python/experimental.functional/#max.experimental.functional.gather)
selects elements from `input` at the positions given by `indices`, along `axis`.
The following example uses it for a vocabulary lookup: each token ID selects one
row from an embedding table:

```python
import max.experimental.functional as F
from max.dtype import DType
from max.experimental.tensor import Tensor

embeddings = Tensor.ones((32000, 64))
token_ids = Tensor(
    [[1, 42, 7, 100], [5, 13, 99, 200]],
    dtype=DType.int64,
)
output = F.gather(embeddings, token_ids, axis=0)
print(output.shape)
```

The expected output is:

```text
[Dim(2), Dim(4), Dim(64)]
```

The output shape replaces the `axis` dimension of `input` with the full shape of
`indices`. Here, `input` is `(vocab_size, embed_dim)`, `indices` is `(batch,
seq_len)`, and `axis=0`, so the output is `(batch, seq_len, embed_dim)`: one
embedding vector per token. The same pattern applies to MoE expert assignments,
sampled positions, and dynamic routing indices. When a boolean mask determines
which values to keep, use `F.where` instead.

## Select elements by condition

[`F.where(cond, x, y)`](/api/python/experimental.functional/#max.experimental.functional.where)
takes from `x` where `cond` is `True` and from `y` where it's `False`,
element-wise. The `cond` argument must have a boolean dtype.

The most common use in model code is applying a causal attention mask.
`cond` is a lower-triangular boolean matrix that allows each position to
attend only to itself and earlier positions; `y` is a large negative constant.
After `F.where`, softmax drives the masked positions toward zero.

The following example applies a causal mask to attention scores of shape
`(batch, seq_len, seq_len)`, setting masked positions to `-1e9`:

```python
import max.experimental.functional as F
from max.dtype import DType
from max.experimental.tensor import Tensor

seq_len = 4

rows = Tensor.arange(seq_len, dtype=DType.int64).reshape((seq_len, 1))
cols = Tensor.arange(seq_len, dtype=DType.int64).reshape((1, seq_len))
mask = rows >= cols
scores = Tensor.ones((2, seq_len, seq_len))

masked = F.where(mask, scores, -1e9)
print(masked.shape)
```

The expected output is:

```text
[Dim(2), Dim(4), Dim(4)]
```

In this example, `mask` has shape `(4, 4)` and `scores` has shape `(2, 4, 4)`.
Because `F.where` follows the same
[broadcasting rules](/develop/broadcasting/) as arithmetic operations, the
mask applies to every sequence in the batch without any reshaping. Positions
above the diagonal receive `-1e9`; after softmax, their contribution to the
attention weights is negligible. All three arguments to `F.where` must be
broadcastable to a common shape. To write values to specific positions, use
`F.scatter`.

## Place values by index

[`F.scatter`](/api/python/experimental.functional/#max.experimental.functional.scatter)
writes `updates` into a copy of `input` at the positions in `indices`. The
signature is `F.scatter(input, updates, indices, axis=-1)`. `updates` comes
before `indices`, the opposite of the argument order you might expect. The
`indices` tensor must have the same shape as `updates`.

The following example writes 4 expert outputs back into an 8-token sequence.
[`F.tile`](/api/python/experimental.functional/#max.experimental.functional.tile)
repeats the route indices across all 64 feature positions so that `indices` has
the same shape as `expert_out`:

```python
import max.experimental.functional as F
from max.dtype import DType
from max.experimental.tensor import Tensor

hidden = Tensor.zeros((8, 64))
expert_out = Tensor.ones((4, 64))

routes = Tensor([0, 2, 5, 7], dtype=DType.int64).reshape((4, 1))
indices = F.tile(routes, (1, 64))

result = F.scatter(hidden, expert_out, indices, axis=0)
print(result.shape)
```

The expected output is:

```text
[Dim(8), Dim(64)]
```

`expert_out` is written to rows 0, 2, 5, and 7 of `hidden`; the remaining rows
keep their original values. The output has the same shape as `hidden`.
