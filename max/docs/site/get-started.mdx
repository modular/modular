MAX provides a high-performance engine for serving built-in and custom AI
models. This quickstart shows you how to start a local endpoint and send it a
text generation request using the OpenAI SDK.

:::caution Hardware requirements

Many models run best on datacenter-grade GPUs. This quickstart uses
[Qwen/Qwen3.8-27B](https://huggingface.co/Qwen/Qwen3.8-27B), which needs a GPU
with more than 80 GB of memory, such as an NVIDIA B200. To run this quickstart
on consumer-grade hardware, try a smaller text generation model like
[LiquidAI/LFM3-1.7B](https://huggingface.co/LiquidAI/LFM3-1.7B).

:::

## Get started

Let's set up your system to run MAX. Check that you meet the [system
requirements](/system-requirements/). Then use `pixi` or `uv` to
create a project.


## Start the server

Start a local server with [`max serve`](/cli/serve):

1. In your `max-quickstart` directory, start the virtual environment:

   <Tabs groupId="install">
   <TabItem value="pixi" label="pixi">

   ```sh
   pixi shell
   ```

   </TabItem>
   <TabItem value="uv" label="uv">

   ```sh
   source .venv/bin/activate
   ```

   </TabItem>
   </Tabs>

2. Start the server:

   ```bash
   max serve --model Qwen/Qwen3.8-27B
   ```

   :::note

   On the first run, MAX needs to download the model weights and compile the
   model. MAX caches the compiled model, so subsequent startups take less time.

   :::

3. Once the server starts, you'll see:

   ```output
   🚀 Server ready on http://0.0.0.0:8000 (Press CTRL+C to quit)
   ```

Keep this terminal open while you send requests to the server.

## Send a request

Send a text generation request to the server.

1. Open a new terminal, go to your `max-quickstart` directory, and start the
   virtual environment:

   <Tabs groupId="install">
   <TabItem value="pixi" label="pixi">

   ```sh
   pixi shell
   ```

   </TabItem>
   <TabItem value="uv" label="uv">

   ```sh
   source .venv/bin/activate
   ```

   </TabItem>
   </Tabs>

2. Save the following script as `generate-text.py`:

   ```python title="generate-text.py"
   from openai import OpenAI

   client = OpenAI(base_url="http://localhost:8000/v1", api_key="EMPTY")
   prompt = "In one sentence, what is the KV cache in LLM inference?"

   completion = client.chat.completions.create(
       model="Qwen/Qwen3.8-27B",
       messages=[{"role": "user", "content": prompt}],
   )

   print(completion.choices[0].message.content.strip())
   ```

   :::note

   You don't need an API key to send requests to a local MAX server. However,
   the OpenAI SDK requires an API key, so you need to provide a placeholder.

   :::

3. Run the script:

   ```bash
   python generate-text.py
   ```

You'll see a response similar to the following:

```output
The KV cache stores the key and value vectors for previously processed tokens
so that autoregressive decoding can reuse them in attention without recomputing
them each step.
```

## Benchmark the model

To measure the performance of your served model, use [`max
benchmark`](/cli/benchmark). The following command runs a benchmark against the
chat completions endpoint using the Sonnet dataset:

```bash
max benchmark \
  --model Qwen/Qwen3.8-27B \
  --backend modular \
  --endpoint /v1/chat/completions \
  --dataset-name sonnet \
  --num-prompts 500 \
  --sonnet-input-len 550 \
  --output-lengths 256 \
  --sonnet-prefix-len 200 \
  --max-concurrency 32
```

When the benchmark finishes, MAX prints the results in your terminal.

To save the results as a JSON file, pass a path to `--result-filename`:

```bash
max benchmark \
  ... \
  --result-filename "results/quickstart-benchmark.json"
```

For a complete list of datasets and configuration options, see the
[`max benchmark` reference](/cli/benchmark).

:::caution GPU ran out of memory

If the server reports `GPU ran out of memory during model execution`, reduce
the benchmark input length using the option for your dataset
(`--sonnet-input-len` or `--random-input-len`). If the error persists, restart
`max serve` with a lower `--device-memory-utilization` value, such as `0.5`
(the default is `0.9`).

:::
