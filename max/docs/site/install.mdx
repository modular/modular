You can install MAX with a Python or Conda package manager on any
[supported system](/system-requirements/). If you use an AI coding assistant,
you can instead [install the MAX skills](/coding-assistants/) and ask
your assistant to install MAX.

<Tabs groupId="install">
<TabItem value="pixi" label="pixi">

1. If needed, install [`pixi`](https://pixi.sh/latest/):

   ```sh
   curl -fsSL https://pixi.sh/install.sh | sh
   ```

2. Create a project:

   ```sh
   pixi init example-project \
     -c https://conda.modular.com/max-nightly/ -c conda-forge \
     && cd example-project
   ```

3. Install `max-all`:

   <ConditionalVersionDocs version="nightly">
   <CodeBlock language="sh">
   {`pixi add max-all`}
   </CodeBlock>
   </ConditionalVersionDocs>
   <ConditionalVersionDocs version="stable">
   <CodeBlock language="sh">
   {`pixi add "max-all==26.7"`}
   </CodeBlock>
   </ConditionalVersionDocs>

   :::note

   This installs MAX with all extra dependencies. You can instead install one of
   the smaller [`max` packages](/packages/).

   :::

4. Start the virtual environment:

   ```sh
   pixi shell
   ```

5. Verify the installation:

   ```sh
   max --version
   ```

</TabItem>
<TabItem value="uv" label="uv">

1. If needed, install [`uv`](https://docs.astral.sh/uv/):

   ```sh
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

2. Create a project:

   ```sh
   uv init example-project && cd example-project
   ```

3. Create and start a virtual environment:

   ```sh
   uv venv && source .venv/bin/activate
   ```

4. Install `max[all]`:

   <ConditionalVersionDocs version="nightly">
   <CodeBlock language="sh">
   {`uv add "max[all]" \\
   --index https://whl.modular.com/nightly/simple/ \\
   --prerelease allow`}
   </CodeBlock>
   </ConditionalVersionDocs>
   <ConditionalVersionDocs version="stable">
   <CodeBlock language="sh">
   {`uv add "max[all]"`}
   </CodeBlock>
   </ConditionalVersionDocs>

   :::note

   This installs MAX with all extra dependencies. You can instead install one of
   the smaller [`max` packages](/packages/).

   :::

5. Verify the installation:

   ```sh
   max --version
   ```

</TabItem>
</Tabs>

<ConditionalVersionDocs version="nightly">

These commands install the nightly build, which isn't complete and might have
new bugs. For the stable build, <Link href="/stable/install/">switch to the
stable docs</Link>.

</ConditionalVersionDocs>
