Mojo's [`layout` package](/api/mojo/layout/) provides a
number of APIs for working with dense multidimensional arrays, which simplify
writing algorithms for handling linear algebra.

This section discusses the `TileTensor` abstraction and its related types:

- [`TileTensor`](/api/mojo/layout/tile_tensor/TileTensor/)
  is a flexible tensor type that combines a `tile_layout.Layout` and a pointer
  to data.
- The
  [`tile_layout.Layout`](/api/mojo/layout/tile_layout/Layout/)
  struct describes an arrangement of data in memory. A *layout* is a function
  that maps a set of logical coordinates (like (*x*, *y*) in a two-dimensional
  array) to a linear index value (such as an offset into a memory buffer).
  Layouts can describe simple row-major or column-major matrices, but also more
  complex organizations, like a matrix subdivided into tiles.
- [`Coord`](https://mojolang.org/docs/std/utils/coord/Coord/) is a tuple-like
  container for storing integer coordinates that supports both compile-time and
  run-time values. It's used for defining logical coordinates and layout shapes,
  among other things.

The `layout` package also includes the older `IntTuple`-based layout type,
`layout.Layout`, which the `Coord`-based layout system replaces for tensors.
`TileTensor` supports layouts with run-time dimensions, nested layouts, and
the `Coord`-based layout system, which minimizes the memory footprint of the
layout struct and can help reduce register pressure on GPUs.

- To step through a buffer of equally shaped tiles, such as the stages of a
  pipelined shared-memory buffer, use
  [`TileTensorIter`](/api/mojo/layout/tile_iterator/TileTensorIter/), as shown
  in [Stepping through a buffer of
  tiles](/tile-tensor/tensors/#stepping-through-a-buffer-of-tiles).
- To walk the tiles of a 2D tensor, loop over the tile coordinates and call
  `tile()` for each one, as shown in
  [Iterating over tiles](/tile-tensor/tensors/#iterating-over-tiles).

You can also convert a `Coord`-based layout into an `IntTuple`-based layout.
For more information on the older layout type, see
[`IntTuple`-based layouts](/layout/layouts/).
